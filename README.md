# 港式麻雀

單檔 HTML 港式麻雀(2–4 人),可對電腦,亦可開房同朋友喺同一個網頁對戰。

## 部署到 GitHub Pages
1. 喺 GitHub 開一個新 repo(Public),例如 `mahjong`。
2. 將 `index.html`、`.nojekyll`、`README.md` 上載到 repo 根目錄。
3. Settings → Pages → Source 揀 `Deploy from a branch`,Branch 揀 `main` / `(root)`,Save。
4. 等一兩分鐘,網址係 `https://<你嘅用戶名>.github.io/mahjong/`。

## 多人對戰
- 一人撳「開房同朋友打」,會得到房號同連結,傳俾朋友。
- 朋友開同一個網頁,輸入房號(或直接開連結)加入。夠唔夠人都可以開始,空位由電腦補。
- 房主嘅瀏覽器負責行牌局,要保持網頁開住。有人斷線會由電腦代打。
- 連線主線路係 Supabase Realtime(Broadcast,同存檔共用同一個 Supabase 專案;專案要開放 public broadcast channel)。同時並行試 PeerJS(WebRTC 點對點),6 秒內都未連到就加開公共 MQTT(HiveMQ / EMQX)備用;邊條線先通就用邊條。MQTT 嘅訊息經公共伺服器,房號唔好公開。
- 房主嘅程式持有所有手牌(信任房主);開始後唔可以中途加入。

## 規則
預設 3 番起糊,144 隻牌連花,詳見遊戲內「睇規則」。

## 存檔(牌局進度)
- 單人對電腦時,每次輪到你、同每局完結,都會自動存檔。重新整理、關咗網頁、隔幾日再開,設定畫面都會見到「繼續牌局」。
- 預設存喺瀏覽器(localStorage);清除瀏覽資料或者換機就冇。
- 想存喺伺服器(換機都繼續得):
  1. 去 https://supabase.com 開一個免費專案。
  2. SQL Editor 貼上 `supabase.sql` 全部內容,撳 Run。
  3. Project Settings → API,抄低 **Project URL** 同 **anon public key**。
  4. 喺 `index.html` 搵 `var CLOUD={url:'',key:''};`,填入兩個值,commit。
  5. 之後設定畫面會顯示你嘅「存檔碼」,換機輸入就可以繼續。
- 安全:表格唔開放直接讀寫,只可以經函數用 16 位私人存檔碼存取;anon key 本身係公開設計,放喺網頁冇問題。存檔碼等於密碼,唔好公開。
- 多人房間(開房同朋友打)暫時唔存檔。

## 自動聽牌
- 手牌只欠一隻牌就可以食糊(聽牌),而且食糊嗰隻牌夠起糊番數時,畫面會出現「自動聽牌 · 欠一隻」掣。番數唔夠(食唔到糊)就唔會出現。
- 自動期間如果有人打出一隻牌,碰咗會令你最高食糊番數增加(而且碰完仍然聽牌),會自動取消自動聽牌,彈出碰/過掣畀你決定。
- 開啟後:有牌食(夠起糊番數)就自動胡;摸到唔啱嘅牌自動打出;如果摸到嘅牌令手牌更接近糊牌,就保留並打出最啱嘅另一隻。自動模式唔會碰、上、槓。
- 隨時可以撳「取消自動」拎返控制權。每局開始會自動重置。

## 介面
- 所有人打出嘅牌放喺中央牌河,每隻牌底下有顏色線標示邊個打出;碰、上、槓嘅牌由牌河拎走。
- 每家一條連續嘅牌架(炭黑色,對手牌背係淺青色,每五隻一組,名牌旁邊有「13 張」牌數):未亮嘅牌、分隔線、再接住碰上槓同花牌,全部貼底靠右。
- 開新遊戲畫面分兩步:牌局設定、點樣玩。
- 舊版介面同 `center.html` 都已經移除,只剩 `index.html`。

## 牌河屏(獨立牌河頁)
- 多人房嘅房主,或者單人對電腦開局後,撳右上角「牌河屏」(多人大廳入面係「開牌河屏」),會見到連結同二維碼,格式係 `index.html?pond=房號`。單人模式會喺背景開一個只供牌河屏用嘅房間,其他玩家入唔到。
- 用平板、電視或者另一部手機打開,只會顯示牌河(每家一種顏色,最後一張有紅框)、碰槓牌、花牌、分數、輪到邊個同每局結果。手牌唔會傳過去,局終先公開。
- 牌河屏係唯讀,唔佔座位,房間開局之後都可以加入;斷線會自動重連。撳「新遊戲」或者離開牌局會關閉牌河屏房間,要再開過。
- 玩家頁面嘅牌河卡有「收埋 / 顯示」掣,收埋後只剩一條細橫條(已打張數同最後打出嘅牌),會記住選擇。
- 二維碼用 CDN 載入 `qrcode-generator`,載入唔到就只顯示連結。
- 局中斷線(或重新整理)會由電腦暫時代打,同一部機自動(或重新輸入房號)再入返就接返原座位同手牌;其他新人局中仍然入唔到。
- 每局完(食糊或流局)結果畫面有 20 秒倒數,夠鐘自動開下一局,唔使等晒所有人撳。
